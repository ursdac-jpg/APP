Changer la couleur de chaque zone du CV

Maquette manipulable, avec deux modèles créatifs. Essayez les deux façons de changer une couleur : le clic direct sur un fond coloré, et le bouton « Modifier les couleurs ».

Règle qui évite les conflits : le clic direct ne marche que sur les fonds colorés sans autre fonction (colonne, bandeau, triangle). Le texte, la photo et les blocs gardent leur comportement : cliquez sur le nom du CV pour le vérifier.
Modèle : Cliquez sur une zone colorée pour changer sa couleur.
Dans le vrai Word : les couleurs suivent automatiquement (le Word est fabriqué à partir du même rendu que le PDF). Je les mesurerai dans Word, modèle par modèle, avant de livrer.
