Votre CV est un peu trop long pour une page.

À l'impression, une deuxième page apparaîtrait avec quelques lignes seulement. Rien n'est perdu : voici comment le faire tenir.

  • Passer en deux colonnes : le CV se range sur la largeur, sans rien retirer.
  • Garder les deux certifications les plus utiles : les autres restent dans votre dossier.
  • Resserrer encore la mise en page : les espaces se réduisent, le texte reste lisible.

Ce que la maquette montre : la hauteur de la feuille est mesurée en direct (une page A4 fait 1 123 px). Proposition 3 reprend votre idée : le rectangle des compétences comportementales passe en deux colonnes (le réglage existe déjà, rectangle par rectangle) et les savoirs remontent sous les compétences professionnelles ; aucun chevauchement. Proposition 1 range les trois rectangles en une seule ligne : le CV très rempli tient, les rectangles ne se chevauchent plus (aujourd'hui le texte du rectangle du milieu passe sous le troisième). Proposition 2 garde l'effet de rectangles superposés, mais gagne moins de place. Le message jaune ne s'affiche que si le CV dépasse, avec le mode sombre prévu.
