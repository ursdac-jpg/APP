À trancher avec Denis

  1. Les mots. Vous aviez écrit « Choisissez ceci si ». J’ai mis « Choisissez ce chemin si » : « ceci » ne dit pas de quoi on parle, « chemin » est le mot déjà utilisé dans tout le module (« Quatre chemins », « Chemin conseillé »).
  2. La place. Sous le titre, avant la description : c’est ce que la personne lit juste après le nom du chemin, au moment de choisir. Le texte, le détail et le bouton restent tels quels.
  3. Plus de chemin conseillé. Le panneau « Par où commencer ? » et l’étiquette « Chemin conseillé » sont retirés : le module ne sait pas pourquoi la personne est là, il montre les quatre chemins à égalité et les phrases « Choisissez ce chemin si » lui permettent de se reconnaître elle-même. Cela retire une fonction (la tuile qui s’allume) : c’est un choix de Denis, pas une perte involontaire. Le code et les tests de cette aide seraient retirés avec elle.
  4. Les vidéos. Voir la réponse de Claude : elles restent au début de chaque chemin, rien n’est ajouté sur les tuiles dans cette version.
  5. Hauteur des tuiles. Chaque tuile gagne deux à trois lignes. Sur téléphone, les quatre tuiles se suivent déjà l’une sous l’autre : le bouton « Voir en largeur de téléphone » ci-dessus montre le résultat.
  6. Le chemin « Je veux écrire ma propre demande » est le seul dont la phrase porte deux conditions (avoir déjà utilisé un assistant ET un sujet absent des modèles). C’est voulu : sinon une personne qui débute le choisirait à la place du chemin 1.
