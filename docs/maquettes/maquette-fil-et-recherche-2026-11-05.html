2. Les fiches de « Comprendre le cadre » dans la recherche de l’accueil (consigne 101)
Aujourd’hui, taper « garde enfant » ne ramène que le nom d’un rayon, pas les fiches. Proposition : un groupe « Dans Comprendre le cadre », classé juste avant « Dans le Lexique », limité à 3 fiches avec un bouton « Voir les autres fiches » (un vrai bouton, pas une ligne de texte soulignée). Un clic ouvre la fiche elle-même, au bon rayon, avec « Retour » vers l’accueil.
