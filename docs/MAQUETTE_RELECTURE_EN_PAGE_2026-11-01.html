Pour me présenter

Points à préparer

    Questions à poser au recruteur

      Ce que cette maquette ne change pas

      • Les mêmes questions, les mêmes propositions d’année, « Je ne sais pas », « Retirer », « 2021 pour toutes » : rien n’est retiré, rien n’est obligatoire.
      • Le contenu envoyé à l’assistant et le contenu des documents : seulement l’endroit où on les relit et les modifie.
      • Les cinq endroits qui ouvrent aujourd’hui « Quelques passages à préciser » (Reformuler, version rapide, Un CV plusieurs métiers, Bilan « Organiser mon CV », Bilan fusion) : chacun garde sa suite, seule la fenêtre disparaît.

      Mes questions pour vous

      Q1. Où placer « Quelques passages à préciser » ?
      A (recommandé) : un bloc en haut de la page qui suit, rouvrable tant qu’on n’a pas validé. Bénéfice : aucune étape de plus dans les barres, on revient quand on veut, c’est le même composant partout. Risque : si la page suivante est déjà longue, le bloc la rallonge.
      B : une étape à part dans la barre. Bénéfice : très visible. Risque : une étape de plus dans les barres de cinq modules (à valider une par une, comme les autres barres).
      Q2. Jusqu’à quand peut-on revenir modifier ses réponses ?
      Recommandé : tant que la page suivante n’est pas validée (puis les réponses sont rangées dans le CV comme aujourd’hui). Risque : demande de garder le texte d’origine pour pouvoir réappliquer une réponse corrigée : c’est la partie délicate du code (aujourd’hui la réponse remplace le texte une fois pour toutes). Alternative plus simple : bloc modifiable jusqu’au clic sur « Terminé », ensuite rangé.
      Q3. « Modifier la lettre » et « Modifier l’entretien » : sur place, comme montré ?
      Recommandé : oui, modification sur place avec « Enregistrer » et « Annuler ». Bénéfice : on garde le reste du document sous les yeux. Risque : la page s’allonge un peu pendant la modification.
      Q4. « Vérifier les informations » : sous le bouton, dans le bloc de l’assistant, comme montré ?
      Recommandé : oui. Une étiquette « Texte modifié à la main » et un bouton « Revenir au texte automatique » rendent l’état clair (aujourd’hui un bandeau l’indique ailleurs).
      Q5. Le mot « Terminé » sur le bloc des passages à préciser : une fois cliqué, le bloc se range en une ligne (« 3 passages précisés · Modifier ») : cela vous convient-il, ou préférez-vous qu’il reste ouvert ?

      Effort et risques

      • Simple (reprise de l’existant) : écrans 2, 3 et 4 : mêmes champs, mêmes enregistrements, seul l’affichage change.
      • Risqué : écran 1 : les réponses sont aujourd’hui appliquées une seule fois, avec une fonction différente selon le module (Reformuler les applique sur les deux versions du CV, les autres dans le dossier). Pour revenir les modifier, il faut les appliquer à partir du texte d’origine à chaque changement.
      • À ne pas oublier : les cinq appelants à tester un par un (parcours réels), et un test automatique du composant partagé.
