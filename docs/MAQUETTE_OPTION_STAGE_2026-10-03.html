Notes de la maquette

  • Constat : aujourd'hui, le stage n'est pas une information captée. Une expérience n'a que : poste, entreprise, lieu, dates, missions. « Stage » ne s'affiche que si la personne l'écrit elle-même dans le poste.
  • Proposition : un petit bouton « Stage » sur la ligne de chaque expérience (même charte que « Missions »), entre le nom et le compteur de missions. Un clic le marque, un second clic le retire : on n'ouvre pas l'expérience.
  • Sur le CV (PDF et Word) : le poste est suivi de « (stage) », par exemple « Agent d'accueil (stage) ». Rien d'autre ne change. L'information est enregistrée avec l'expérience.
  • À l'import : si l'assistant reconnaît un stage dans le texte, il pourra pré-cocher le bouton ; la personne garde le dernier mot.
  • À trancher avec Denis : le mot exact affiché (« (stage) » seul, ou aussi « (stage de formation) », « (stage d'immersion) » comme dans le choix de l'objectif) ; le sort des expériences déjà importées (rien n'est coché d'office) ; le bouton est-il aussi proposé dans la fenêtre d'édition d'une expérience (oui, même état).
