## 2. Décisions de Denis (29/10/2026) : DEUX NIVEAUX, boutons SAUMON

1. **Deux niveaux de prompt**, pour combler les trous de l'un par l'autre :
   - **groupe** (8 fiches au plus, les premières de la liste affichée) : sert à **trier**. L'assistant répond « confirmé / à regarder / introuvable » avec la page lue, **sans proposer de valeur à recopier** (pas de « Mettre dans la carte » depuis un groupe). Le résultat est marqué « de groupe » : un tri, pas une vérification ;
   - **individuel** (une fiche) : c'est lui qui **fait foi**. Il propose les valeurs corrigées et le bouton « Mettre dans la carte ».
   Raison de la règle : l'assistant risque d'inventer quand il y a trop d'éléments dans un prompt ; le groupe sert à repérer, l'individuel à trancher. Dans les deux cas Denis ouvre la source et décide ; rien n'est daté ni validé automatiquement.
2. **Tous les boutons de vérification avec un assistant ont une couleur à eux, le saumon**, pour que Denis les repère d'un coup d'œil parmi les autres boutons (ce sont ceux qu'il jouera le plus). Classe commune `.btn-verif`, avec sa valeur en mode sombre (`--verif`, `--verif-bg`, `--verif-texte`). Une seule définition, réutilisée partout (à inscrire dans `docs/BRIQUES_COMMUNES.md`).
3. Extension : Qui fait quoi d'abord, puis présentation de la suite (Lexique y compris les mots à comprendre, fiches du cadre, adresses, chiffres), puis T7 (outil de prospection).

**Un seul constructeur** de prompt, partagé :
- base : le complément qui marche (règle par cas `confirmé / corrigé / non vérifiable / fermée ou absente`, annuaires interdits, aucun commentaire) ;
- consignes par **type d'élément** : employeur, structure, agence d'intérim, page d'offres, page de recrutement, adresse de fiche, mail, mot du Lexique ;
- le prompt contient la valeur actuelle, **où la retrouver** et la source exacte attendue ; le groupe répète le même bloc pour 8 fiches ;
- retour à format fixe (individuel : champ | statut | valeur lue | URL exacte | phrase lue ; groupe : numéro | nom | statut | ce qui diffère | URL), relu par le code.
