# Échantillon de 30 fiches du ROME générées par le code (consigne 263, phase 1)

Généré le 2026-11-13 à partir du ROME 4.0 (Numero de version : 62 | Date de publication : 19/10/2026 | Date de validation : 26/08/2026). **Rien n'est encore branché à l'application.**

**Comment lire** : pour chaque métier, « Ce que dit le ROME » rappelle les grands thèmes de la fiche officielle ; « Ce que le code en déduit » est ce que l'application utiliserait. Il suffit de répondre pour chaque fiche : **juste**, **à peu près** ou **faux** (et ce qui manque ou gêne). Les listes sont plafonnées exprès (actions 6, publics 3, matières 3, lieux 3, savoir-faire 6, savoir-être 4, savoirs 6).
