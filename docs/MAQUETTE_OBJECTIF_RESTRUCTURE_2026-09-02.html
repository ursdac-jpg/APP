Ce qui a changé (v3 puis v4)

Passe visuelle (v4)

  • Jetons de choix modernisés : case à cocher pour les choix multiples (contrat, disponibilité...), rond pour les choix uniques (métier ou domaine, type de recherche). Coin arrondi, plus de place pour le doigt, coche visible une fois sélectionné.
  • Champs de saisie : plus grands, coins arrondis, halo discret quand on écrit dedans.
  • Titres de rubriques et libellés un peu plus lisibles.
  • Cette passe est à généraliser comme composant partagé (jetons + champs), pas seulement sur cet écran : contrat / disponibilité / etc. apparaissent ailleurs dans l'app.

Champ « Quel métier ? »

  • Plus aucun message « connu / pas connu ». On ne juge pas le métier saisi.
  • Saisie assistée : la base (une centaine de métiers) est proposée pendant la frappe. Première lettre en majuscule automatique.
  • Validation clavier (Entrée) OU souris (bouton « Valider », ou clic sur une suggestion). Un métier libre, absent de la base, se valide exactement pareil.
  • Une fois validé, le métier apparaît en dessous sous forme de pastille avec une croix pour le retirer. Valeur unique : une nouvelle saisie remplace la précédente, jamais d'empilement.
  • Encart « En savoir plus sur ce métier » sous la pastille : affiché pour tout métier retenu, connu ou non. Un bouton (pas un lien texte), le clic ouvre France Travail dans une nouvelle page, le parcours reste ouvert ici. Deux cas :
    • Métier de notre base (nous avons son code ROME sur les 65 fiches) : bouton « Consulter la fiche sur France Travail » → ouverture directe de la fiche. Message ajouté : les fiches évoluent ; si elle a disparu, chercher dans le répertoire.
    • Métier hors base : bouton « Rechercher ce métier sur France Travail » → ouvre le répertoire des métiers, prêt à taper le nom. On épargne à la personne d'ouvrir un onglet, de chercher France Travail et de retrouver le chemin.
    Dans les deux cas, aucun mot « reconnu / pas reconnu » : la personne ne sait pas si nous avons la fiche ou non, seule la destination du bouton change.

À confirmer au moment du code : l'URL exacte d'une fiche France Travail par code ROME, et l'URL du répertoire de recherche. Aussi : certains codes ROME de la base peuvent dater d'une ancienne version (v3) et ne plus correspondre. Le message « si la fiche n'apparaît pas, cherchez dans le répertoire » couvre ce cas ; un rafraîchissement des codes ROME serait une petite tâche à part.

Choix « Plusieurs métiers d'un domaine »

  • Un menu déroulant (plus de mur de pastilles). Domaines en ordre alphabétique, « Autre (préciser) » en tête.
  • « Autre » ouvre un champ texte (première lettre en majuscule), validé au clavier ou à la souris.
  • Même comportement que le métier : valeur unique, pastille + croix pour retirer.
  • Liste provisoire : la vraie liste (une trentaine de domaines) se calera avec le chantier « secteurs de métier ».

Stage / alternance / PMSMP

  • « Votre candidature » identique pour les 3 : métier ou domaine + structure + lien.
  • Bloc commun aux 3 : disponibilité + période/dates + durée + heures par semaine (désormais pour stage et alternance aussi, pas seulement l'immersion).
  • Alternance : pas de bloc « conditions de travail ».
