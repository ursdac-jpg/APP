Sept compositions très différentes pour le bandeau et la colonne

Ce sont de vrais CV de l'application (vrai texte), habillés par du CSS : ce que le code produirait. Chaque composition est un style complet à choisir d'un clic, pas un réglage à bricoler. Toutes respectent vos règles : jamais toute la feuille colorée, texte toujours lisible, rien d'illisible à l'impression.

Ma vision, en trois idées directrices

1. Proposer des styles finis, pas des curseurs. Une personne peu à l'aise n'étire rien : elle choisit une composition, et le CV est beau d'emblée. Le réglage fin reste possible ensuite, mais ce n'est pas la porte d'entrée.

2. Jouer sur la relation, pas sur la décoration. Le bandeau et la colonne peuvent se fondre (L), se croiser (superposition), se couper (diagonale), se chevaucher (carte, onglet) ou se faire oublier (équerre). Chaque relation raconte quelque chose de différent sur la personne.

3. Penser encre et lecture automatique. Plusieurs compositions (équerre, teintes superposées) utilisent très peu d'encre et gardent le texte sur fond blanc ou très clair : elles s'impriment bien et se lisent bien par les logiciels de tri.

1La plaque de titre

Colonne foncée sur toute la hauteur ; le titre du CV est posé sur une plaque claire aux coins arrondis, détachée du bord. Le plus « éditorial ».

2La diagonale partagée

Une seule ligne oblique sépare la zone claire (nom, coordonnées) de la zone foncée (titre) : bandeau et colonne ne font plus qu’un dessin, plus dynamique.

Valeur visuelle : 5 sur 5   Code : Moyenne   Encre : Moyenne
Word : Attendu : oui (formes à angles, comme les modèles à diagonale)

3L’équerre

Presque pas de fond : seulement deux grandes équerres épaisses dans les coins opposés de la page, comme un cadre ouvert. Très peu d’encre, très lisible.

Valeur visuelle : 4 sur 5   Code : Facile   Encre : Très faible
Word : Attendu : oui (traits épais)

4Le L d’un seul tenant

Bandeau et colonne d’une seule couleur, en un seul bloc en L au coin intérieur arrondi : très sobre, très reconnaissable.

Valeur visuelle : 4 sur 5   Code : Facile   Encre : Forte
Word : Attendu : oui, sauf l’arrondi intérieur (coin droit)

5Les teintes superposées

Le bandeau et la colonne sont deux teintes claires de la même couleur ; là où elles se croisent, une troisième teinte, plus soutenue. Tout le texte est sombre.

Valeur visuelle : 4 sur 5   Code : Facile   Encre : Faible
Word : Attendu : oui (trois rectangles de teintes fixes, sans mélange)

6L’onglet de classeur

La colonne foncée dépasse du haut comme un onglet de classeur, avec le nom dedans ; le bandeau clair passe derrière.

Valeur visuelle : 3 sur 5   Code : Facile   Encre : Moyenne
Word : Attendu : oui (rectangle arrondi en haut)

7La carte qui chevauche

Bandeau foncé ; une carte claire (la colonne) monte à moitié sur son bord bas, cernée d’un liseré blanc.

Valeur visuelle : 3 sur 5   Code : Facile   Encre : Moyenne
Word : Attendu : oui (rectangle arrondi et liseré)

Mon classement honnête

CompositionPourquoiRisque
1. La plaque de titreLe plus fort visuellement, le plus « magazine ». Donne enfin la colonne pleine hauteur avec un titre mis en valeur.Faible : rectangles et arrondis simples.
2. La diagonale partagéeTrès différent de tout ce qui existe ; dynamique ; un seul dessin pour les deux éléments.Moyen : bien régler l'angle et le texte à cheval.
3. L'équerreTrès peu d'encre, très lisible, élégant, rassurant pour un public prudent.Faible.
4. Le L d'un seul tenantSobre et net. L'arrondi intérieur sera un coin droit dans le Word.Faible.
5. Les teintes superposéesSubtil, raffiné, tout le texte sombre. Moins spectaculaire.Faible.
6, 7. Onglet, carte qui chevaucheJolis mais proches de modèles qui existent déjà (carte, colonne claire).Faible, valeur ajoutée limitée.

Mon conseil : garder les trois premières (plaque, diagonale, équerre), qui sont réellement différentes de l'existant, et laisser les autres de côté. Ces styles seraient proposés comme des compositions à choisir sur les modèles à bandeau et colonne, avec le texte qui s'adapte seul.
