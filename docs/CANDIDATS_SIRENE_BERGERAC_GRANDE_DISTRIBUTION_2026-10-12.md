## 4. Limites constatées
- Des établissements voisins hors Bergerac (Creysse, Saint-Laurent-des-Vignes) portent le code postal 24100 : le « bassin » n'est pas le code postal.
- Une société peut regrouper plusieurs magasins d'une même enseigne (indépendants adhérents) : la tranche d'effectif est celle de la société, pas du magasin.
- Aucun indicateur de recrutement n'existe dans cette source : ne jamais écrire « recrute régulièrement ».
