# source, c'est ici qu'on edite.

# ==========================================================================
#  FORMAT D'UNE LIGNE :  nom-court | adresse | date de verification | portee
#     (les separateurs sont des barres verticales, entourees d'espaces)
# ==========================================================================
#
#  Une adresse ne devient un LIEN CLIQUABLE en pied de fiche que si la
#  3e colonne (la date) est remplie. Tant qu'elle est vide, le nom du site
#  s'affiche en texte simple, avec la mention « adresse pas encore verifiee ».
#
#  ---- Dater une source documentaire (paquet B) ----
#  1. Ouvrir l'adresse (2e colonne) dans le navigateur.
#  2. Verifier qu'elle pointe bien sur le bon sujet, et que la page est vivante.
#  3. Ecrire la date du jour dans la 3e colonne, au format AAAA-MM-JJ.
#     Si la page a bouge : corriger d'abord l'adresse (2e colonne), puis dater.
#  4. Enregistrer. Rien d'autre : le lien devient cliquable tout seul.
#
#  Avant :  service-public-rsa | https://www.service-public.gouv.fr/particuliers/vosdroits/N19775 |  | national
#  Apres :  service-public-rsa | https://www.service-public.gouv.fr/particuliers/vosdroits/N19775 | 2026-09-20 | national
#           (la date est simplement ajoutee entre la 2e et la 4e barre)
#
#  ---- Dater une structure « a qui s'adresser » (paquet C) ----
#  Meme geste, plus la 4e colonne = la PORTEE de la structure :
#     national  = vaut partout en France, affichee pour tout le monde
#     region    = Nouvelle-Aquitaine, affichee pour un utilisateur 24 ou 87
#     24        = Dordogne uniquement
#     87        = Haute-Vienne uniquement
#  4e colonne vide = pas encore taguee : la structure s'affiche pour tout le
#  monde, dans une section « A verifier selon votre territoire ».
#

#  Apres :  mission-locale-perigord | https://www.missionlocaleduperigordnoir.fr/ | 2026-09-20 | 24
#           (ici l'adresse nationale a ete remplacee par le vrai site local, puis datee)
#

#  par nature : laisser leur portee vide, ou ecrire "national".
