# Rayon « Moins de 26 ans » : 6 fiches

**Statut : relu et validé par Denis le 2026-09-06.** Recherche web sur les pages officielles (service-public.gouv.fr,
ministère du Travail, ministère de l'Éducation nationale, Agence du service civique), consignée dans
`jeunes.collecte.md`.

## Avant de publier

1. **Relire les 6 fiches** dans `outils/veille.html`.
2. **Vérifier les adresses** de `../../liens-verifies.txt` : `sources:` (10), `structures:` (9).
3. **Points sensibles à confirmer** (recherche de septembre 2026) :
   - CEJ : allocation jusqu'à **566,17 €/mois au 1er avril 2026**, 15-20 h/semaine, 1 an + 6 mois ;
   - E2C : ~500 €/mois (>18 ans), ~200 € (16-18) ; EPIDE : allocation 460 €/mois + prime ~106 € à la
     sortie ;
   - service civique : indemnité **504,98 €** + prestation de subsistance **114,85 €** + complément
     ~115 € pour boursiers / RSA ;
   - obligation de formation 16-18 : loi de 2019, contrôle confié aux Missions locales ;
   - prépa-apprentissage : 16-29 ans, financée par le plan d'investissement dans les compétences.
