# Rayon « Handicap et emploi » : 9 fiches

**Statut : relu et validé par Denis le 2026-09-06** pour les 7 premières fiches, **et le 2026-09-11**
pour les 2 suivantes (pension d'invalidité, proche aidant/AJPA) : trouvées absentes du rayon lors d'un
balayage complet du Lexique contre « Comprendre le cadre », sources vérifiées une par une par Denis
le 2026-09-11, dates reportées dans `liens-verifies.txt`. Recherche web sur les pages officielles
(service-public.gouv.fr, ministère du Travail, AGEFIPH, ameli.fr, pour-les-personnes-agees.gouv.fr),
consignée dans `handicap.collecte.md`.

## Avant de publier

1. **Relire les 6 fiches** dans `outils/veille.html`.
2. **Vérifier les adresses** de `../../liens-verifies.txt` : `sources:` (12), `structures:` (7).
3. **Points sensibles à confirmer** (recherche de septembre 2026) :
   - RQTH : durée 1 à 10 ans, parfois à vie ; **RQTH automatique pour les jeunes de 15-20 ans
     bénéficiaires de l'AEEH / PCH / PPS sur présentation du document**, à confirmer ;
   - **offre de services et d'aides de l'AGEFIPH révisée le 1er octobre 2025** (ligne `revisions:`
     dans la fiche AGEFIPH) ;
   - inaptitude : obligation de reclassement de l'employeur et ses exceptions ; indemnité doublée si
     inaptitude d'origine professionnelle ;
   - reconnaissance de la lourdeur du handicap : aide ~6 770 € / an (taux normal), ~13 479 € (majoré) ;
   - OETH : 6 % à partir de 20 salariés ; fin de l'écrêtement depuis le 1er janvier 2025.
4. **Les 2 fiches du 2026-09-11 sont désormais validées.** Sources vérifiées au navigateur par Denis
   le 2026-09-11 et datées dans `liens-verifies.txt` : `ameli-demander-pension-invalidite`,
   `ameli-entree-invalidite`, `pour-les-personnes-agees-conge-proche-aidant`, `pour-les-personnes-agees-ajpa`.
