# Rayon « Questions juridiques » : 6 fiches

**Statut : relu et validé par Denis le 2026-09-06.** Recherche web sur les pages officielles (service-public.gouv.fr,
code du travail numérique, justice.fr, France Travail, Défenseur des droits, CAF), consignée dans
`juridique.collecte.md`.

Ce rayon **oriente** vers les bons interlocuteurs, il n'apporte pas de conseil juridique
personnalisé. `frein: false` sur le panorama et l'aide juridictionnelle (des enablers) ; `frein: true`
sur les quatre fiches de litige. **Ton : jamais alarmiste, toujours une porte de sortie concrète,
jamais de diagnostic sur la personne.**

## Avant de publier

1. **Relire les 6 fiches** dans `outils/veille.html`.
2. **Vérifier les adresses** de `../../liens-verifies.txt` : `sources:` (10), `structures:` (8).
   Plusieurs sources CAF sont des pages départementales : trouver l'équivalent générique ou la page
   Dordogne avant publication.
3. **Points sensibles à confirmer** (recherche de septembre 2026) :
   - **timbre fiscal de 50 euros** pour saisir une juridiction civile ou le conseil de prud'hommes
     depuis le 1er mars 2026, exonération pour l'aide juridictionnelle (deux lignes `revisions:`) ;
   - aide juridictionnelle : plafonds 2026 à vérifier (revenu fiscal de référence de l'ordre de
     13 000 euros pour l'aide totale, personne seule), formulaire Cerfa n° 15626 ;
   - prud'hommes : délais de prescription (12 mois licenciement, 2 ans exécution du contrat, 3 ans
     salaires), barème dit « Macron » de 3 à 20 mois, non applicable en cas de nullité ;
   - Défenseur des droits : réseau de délégués territoriaux ; la saisine ne suspend pas les délais de
     prescription ;
   - France Travail : médiateur régional préalable obligatoire pour les sanctions et fins
     d'inscription ; RSA contesté auprès du président du conseil départemental ;
   - CAF : commission de recours amiable dans les 2 mois.

## Recoupements

- Rupture du contrat, licenciement économique, contrats d'insertion : rayon Emploi.
- Recours MDPH, reconnaissance de l'inaptitude : rayon Handicap.
- Recours contre une décision de la préfecture (séjour) : rayon Étranger.
- Surendettement, saisies, expulsion : rayons Budget et Logement (volet « faire valoir ses droits »).
